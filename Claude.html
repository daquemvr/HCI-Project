ABOUT THE PROJECT

About Snap-to-Stop

A smart alarm system for students.

📸

What is Snap-to-Stop?

Snap-to-Stop is a smart alarm website designed to help students remember their homework and activities.

Instead of simply pressing a stop button, you must complete a Snap Challenge: the app shows a random object and you must capture it with your camera using real AI object detection.

How it works

1

Set an alarm

2

Wait until the time

3

Alarm starts ringing

4

A random object appears

5

Capture the correct object

6

Alarm automatically stops
